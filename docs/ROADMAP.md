# Roadmap

## Completed prototype

The smallest synthetic-data Care Loop is implemented with seven original actions, transparent mapping, mock campus support, temporary reflection, routine preferences and help information. The original Vite source is preserved. Lint, strict typecheck, eight tests and production build passed. After user approval, the user deployed the corrected Next.js app to Vercel and confirmed it worked on 17 October 2026.

## Next review

Run the manual checks in [TESTING.md](TESTING.md), including screen-reader/mobile evaluation, then conduct 3–5 student usability sessions with invented scenarios. Include international students where possible. Review language, mapping explanation, support-label comprehension and understanding of data clearing. No health data collection is planned through this prototype.

Prioritize fixes based on observed confusion before adding features. Next-specific ESLint rules remain a tooling follow-up. Automatic Git deployment and production branch selection require explicit verification before relying on them.

## Separate decisions

With separate approval, investigate ownership of verified support information and whether persistence is justified; define jurisdiction-specific help and privacy/security requirements.

Accounts, stored journals, real notifications, live contacts, chat and bookings remain deferred. Deployment was approved for the current prototype; future releases, public-access changes and production configuration changes should be deliberate. No clinical effectiveness claim is supported.
